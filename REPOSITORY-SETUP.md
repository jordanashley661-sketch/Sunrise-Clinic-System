# Required GitHub submission

The summative brief requires an assessor-accessible GitHub repository. This package is prepared for a repository, but no remote repository has been created and no URL is claimed.

1. Create a GitHub repository for this project under your own account.
2. Upload the extracted project files, preserving the sunrise, tests and evidence folders. Keep README.md at the repository root.
3. Do not upload patient databases, credentials for real accounts or confidential exports. The supplied .gitignore excludes local database and CSV files.
4. If private, grant the assessor access as your institution directs. Verify that access works.
5. Add the actual repository URL to the final report and submission fields.
6. Keep source-code.pdf aligned with the exact submitted source. Re-run tests and regenerate the source PDF after changes.

README.md records AI assistance and actual verification limits. Do not represent test fixtures as real patient use or automated tests as your own manual acceptance results.
